# N&N Digitals

Static landing page for the N&N Digitals product studio.

## Local preview
Open `index.html` in a browser.

## GitHub Pages
1. Open repository **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch `main` and folder `/ (root)`, then Save.
4. GitHub will publish the site at the repository's Pages URL.

## Custom domain
After the domain is registered, add it under **Settings → Pages → Custom domain**. Then configure the DNS records shown by GitHub for the domain registrar. Verify domain ownership before connecting DNS. Enable **Enforce HTTPS** once it becomes available.

The first product card is intentionally a launch placeholder until the extension's exact public name, description and Chrome Web Store URL are confirmed.
